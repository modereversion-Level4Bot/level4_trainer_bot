## Что такое этот проект

**Level4Trainer** — Telegram-бот для пилотов, которые готовятся к экзамену по английскому языку по шкале ИКАО.

Бот помогает:
- тренировать грамматику (📘 Grammar)
- отрабатывать экзаменационные вопросы с аудио (🎙 Questions)
- проходить ролевые сценарии пилот-диспетчер (🛫 Routes)
- настраивать личные параметры (⚙️ Settings)
- администрировать контент (🛠 Admin)

Целевая аудитория: русскоязычные пилоты. Интерфейс двуязычный — RU/EN.

## Ключевые архитектурные принципы

### 1. Модульный монолит
Один сервис, но чётко разделённый по папкам. Каждый модуль в `features/` отвечает за одну функцию бота.

### 2. Clean Chat — одно главное сообщение
Главный UX-принцип: у каждого пользователя в чате всегда одно активное UI-сообщение.
При переходах оно обновляется, а не создаётся новое. Временные медиа (аудио вопросов) удаляются после показа.

### 3. Разделение слоёв
- `handlers.py` — принимает событие от Telegram, вызывает service
- `service.py` — бизнес-логика, оркестрация
- `repositories/` — только работа с базой данных, ничего лишнего

### 4. Safe Telegram
Все обращения к Telegram API идут через обёртки в `core/safe_telegram.py`.
Ошибка у одного пользователя не должна ронять весь бот.

### 5. Google Sheets → SQLite
Контент хранится в Google Sheets, импортируется в SQLite скриптами.
В runtime бот работает только с SQLite, к Sheets не обращается.

### 6. Аудио через file_id cache
Аудио вопросов не отправляется из файла каждый раз.
Сначала `scripts/preload_question_audio.py` загружает файлы в Telegram и сохраняет `file_id`.
В runtime бот отправляет аудио по `file_id` — быстро и надёжно.

## Технический долг (важно знать)

## Правила работы с кодом

- Перед изменением файла — прочитать его полностью
- Не трогать схему БД без понимания миграций (папка `db/schema/`)
- Изменения в `routes/` согласовывать с Константином — модуль в активной разработке
- `.env` и `secrets/` — никогда не коммитить, не логировать
- После изменений в репозиториях — проверить, что `smoke_check.py` проходит
